# smartphone-usage-digital-wellbeing
📌 Project Overview

This is a Power BI demo project focused on exploring smartphone usage patterns and their relationship with digital wellbeing. The dashboard presents insights into screen time, sleep duration, stress levels, addiction risk, productivity, and user demographics.

🎯 Project Objectives

*Analyze daily smartphone screen time and phone pickups.

*Explore the relationship between screen time and sleep duration.

*Understand stress levels and addiction risk categories.

*Examine productivity and sleep-related patterns.

*Explore user demographics by age group, gender, region, and occupation.

📊 Dashboard Pages

1. Usage Analysis

*Average screen time

*Phone pickups and notifications

*Daily screen time trends

2. Digital Wellbeing & Addiction

*Screen time and sleep duration analysis

*Addiction risk distribution

*Stress level by risk level

*Sleep and productivity analysis

3. Demographics

*Users by age group

*Gender distribution

*Users by region

*Users by occupation

*Risk level by age group
